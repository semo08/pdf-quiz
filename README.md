# PDF-Quiz

코딩 시험, 자격증 실기 등 **코드 트레이싱 / 빈칸 채우기 / 키워드 암기** 유형의 문제를 PDF로 업로드하면 바로 문제풀이 앱으로 변환해주는 웹 앱입니다.

**👉 [바로 사용하기](https://semo08.github.io/pdf-quiz/)**

---

## 어떤 문제에 쓰나요?

- **코드 출력 결과 맞추기** — C, Java, Python 코드 스니펫을 보고 실행 결과를 입력
- **SQL 작성 / 빈칸 채우기** — 쿼리 결과나 빠진 키워드 입력
- **키워드 암기** — 개념 설명을 보고 해당 용어 입력

카테고리를 **Python / C / SQL / Java / Plain text** 중 하나로 지정하면, 코드 스니펫이 해당 언어에 맞는 문법 강조(syntax highlight)와 색상으로 표시됩니다.

---

## 사용 방법

### 1단계 — PDF 업로드 및 파싱

1. **PDF 업로드** 영역에 파일을 드래그&드롭하거나 클릭해서 선택합니다. (여러 개 동시 선택 가능)
2. **파싱 시작 →** 버튼을 누르면 문제·코드·정답·해설을 자동으로 추출합니다.

### 2단계 — 파싱 결과 검토 및 편집

- 테이블에서 파싱된 문제 목록을 확인합니다.
- **편집** 버튼으로 카테고리, 문제, 코드, 정답, 해설을 수정할 수 있습니다.
- 문제집 이름을 입력한 뒤 **완료 + JSON 저장 →** 를 누르면 `.json` 파일로 저장되고 문제풀이 화면으로 이동합니다.

### 3단계 — 문제 풀이

좌측 사이드바에서 문제집과 카테고리를 선택하고, 상단 탭바로 문제 번호를 이동합니다.

1. 코드 스니펫이나 지문을 읽고 정답을 입력 후 **확인** 또는 **Enter**
2. ✅ 정답 / ❌ 오답 + 정답 표시, 해설이 있으면 **해설 보기 ▼** 로 확인
3. 진행률은 자동 저장됩니다.

문제 우측 상단 **편집** 버튼으로 풀이 중에도 수정할 수 있습니다.

---

### 다른 기기에서 사용하기

1. 사이드바 하단 **💾 JSON 저장** → `.json` 파일 다운로드
2. 다른 기기에서 앱 접속 후 **JSON 불러오기** 영역에 파일 드래그&드롭 → 바로 시작

---

## 주의사항

- PDF와 문제 데이터는 브라우저 내에서만 처리되며 서버로 전송되지 않습니다.
- 저장 데이터는 브라우저 localStorage에 보관되므로, 브라우저 초기화 전에 JSON으로 백업해두세요.
- PDF 구조에 따라 파싱 품질이 다를 수 있습니다. 검토 화면에서 편집 후 사용하세요.
